# Release changes

Read [.egohygiene/release.json](.egohygiene/release.json), [CHANGELOG.md](CHANGELOG.md)
and [the release guide](docs/release.md) before changing release behavior.
Follow [CONTRIBUTING.md](CONTRIBUTING.md), [ARCHITECTURE.md](ARCHITECTURE.md)
and [PROVENANCE.md](PROVENANCE.md). Release preparation is reviewable source work;
tagging, signing and publication require a separate approved manual handoff.
